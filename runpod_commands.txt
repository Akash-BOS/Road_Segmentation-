Runpod Command Reference

1. Connect to Runpod SSH
ssh cxov3dyqb5jw3s-64411bea@ssh.runpod.io -i "C:\Users\Admin\.ssh\id_ed25519_akash"

2. Verify GPU on the pod
nvidia-smi

3. Clone repo on the Runpod pod
cd /root
git clone https://github.com/Akash-BOS/Road_Segmentation-.git
cd Road_Segmentation-

4. Install Python dependencies
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

5. Prepare remote data folder
mkdir -p /root/data

6. Upload data from Windows using SCP (local command)
scp -i "C:\Users\Admin\.ssh\id_ed25519_akash" -r "F:\Akash\Data\25thjuly\newData_v1" cxov3dyqb5jw3s-64411bea@ssh.runpod.io:/root/data

7. Upload using exposed TCP port (local command)
scp -i "C:\Users\Admin\.ssh\id_ed25519_akash" -P 22084 -r "F:\Akash\Data\25thjuly\newData_v1" root@69.30.85.113:/root/data

10. Run training without ClearML

14. Download the whole output folder using direct TCP port (local Windows PowerShell)
scp -i "C:\Users\Admin\.ssh\id_ed25519_akash" -P 22084 -r root@69.30.85.113:/root/weights/lcms_unetpp "C:\Users\Admin\Downloads\lcms_unetpp"

Important notes:
- Use Windows paths only on your local machine, not inside the pod.
- Use Linux paths inside the Runpod pod.
- If ClearML cannot connect, use --no-clearml.
- If the data is already on the pod, use /root/data/newData_v1 as --data-path.
